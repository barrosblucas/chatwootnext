# Changelog

Histórico diário e incremental das mudanças.
**Não carregar por padrão.** Use só quando a tarefa pedir histórico.

## Arquivo
- Um arquivo por dia: `changelog/CHANGELOG_AAAA_MM_DD.md` (ex.: `CHANGELOG_2026_10_19.md`).
- Se o arquivo do dia já existe, anexe a nova entrega no fim. Não recrie nem apague entradas antigas.

## Formato
```
# Changelog AAAA-MM-DD

## Added
- ...

## Changed
- ...

## Fixed
- ...

## Removed
- ...

## Tests
- ...

## Docs
- ...
```

Seções sem itens podem ser omitidas. Cada item é uma linha, no passado, descrevendo o efeito (não o diff). Cite o caminho quando ajudar (ex.: `src/billing/fee.ts`).
